Đăng ký user (POST /auth/register)
Body (JSON):
{
"name": "Admin Test",
"email": "admin@example.com",
"password": "changeme"
}
Kết quả: hệ thống có thể gửi OTP qua email (nếu cấu hình mail hoạt động). Nếu không cần OTP để test, bạn có thể trực tiếp bật user trong DB hoặc dùng endpoint verify nếu có OTP.
Xác thực email nếu cần (POST /auth/verify)
Body (JSON):
{
"email": "admin@example.com",
"otp": "123456"
}
Đăng nhập để lấy token (POST /auth/login)
Body (JSON):
{
"email": "admin@example.com",
"password": "changeme"
}
Response: { "access_token": "jwt.token.here", "user": { ... } }
 POST /api/colors Tạo màu
 {
  "name": "Red",
  "hexCode": "#FF0000"
}
GET /api/colors Lấy tất cả màu
GET /api/colors/{id} Lấy chi tiết màu theo ID
Lấy id từ lúc post sẽ hiện thị 
  "id": "c78e343b-950c-4faa-9b6b-8fa2612dcb27",
Thay "id": vào {id}
PUT api/colors/{id} #Cập nhật màu
{
  "name": "Bright Red",
  "hexCode": "#FF3333"
}
DELETE /api/colors/{id} #Xóa màu theo ID
